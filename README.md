# iRing – website

Static pages for the iRing iOS app, served with GitHub Pages:

- `/` – landing and support contact (App Store Connect **Support URL**)
- `/privacy/` – privacy policy in Italian and English (App Store Connect **Privacy Policy URL**)

Language: `?lang=it` or `?lang=en`, otherwise the browser language. No build step, no trackers, no external requests.

When the policy changes, update the "last updated" date in both languages in `privacy/index.html`.
